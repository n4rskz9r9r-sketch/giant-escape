# 거인과 도망자 3D — AI 대결 · 공진화 (현재 v11: 벽 부수기 능력 · 거인 증원 · 뷱 1마리)

도망자 1명과 거인 3명이 대결하는 정적 웹 게임입니다. 빌드 과정이 없고 실행할 때 CDN도 쓰지 않습니다.

## 실행
- `cd /workspace/ai-giant-escape && python3 -m http.server 8765` 후 http://localhost:8765 에 접속합니다.
- 3D는 ES 모듈을 쓰므로 http로 열어야 합니다.
- `file://`로 열거나 WebGL이 없는 기기에서는 2D 화면으로 자동 전환됩니다.

## 파일
- `index.html`: v3 화면
- `css/style3.css`
- `js/engine3.js`: 미로, 규칙, 도망자 AI, 거인 3명 팀 AI, 유전 알고리즘. Node에서도 동작합니다.
- `js/ui3.js`: 조작, 2D 화면과 미니맵, 패널, 차트
- `js/render3d.js`: three.js 3D 렌더러 (ES 모듈)
- `js/vendor/`: three.js r186 (`three.module.js`, `three.core.js`), `OrbitControls.js`, MIT 라이선스
- 이전 버전: `index.v2.html`, `js/engine.js`, `js/ui.js`, `css/style.css` (문 2개, 거인 1명)

## v3 규칙
- 미로는 31×21이고 고리가 많습니다.
- 열쇠 2개를 모으면 문 A·B가 열립니다. 도망자는 거인들에게서 더 안전한 문을 고릅니다.
- **거인**
  - 3명이 각자 유전자 10개를 가집니다: 속도 집중, 길목 차단, 예측 거리, 매복, 돌진, 끈기, 냄새, 출구 감시, 흩어지기, 호출.
  - 역할(추격조·차단조·매복조)은 유전자 값으로 정해집니다.
  - 팀 협동:
    - 도망자를 본 거인이 동료를 부릅니다(호출).
    - 동료와 흩어져 포위합니다.
    - 같은 칸에는 겹칠 수 없습니다.
    - 매복할 때 서로 다른 열쇠를 지킵니다.
    - 문마다 감시하는 거인은 최대 1명입니다.
  - 문 칸에는 들어갈 수 없고, 문 근처에서 8턴 넘게 머물면 14턴 동안 접근이 금지됩니다(거인마다 따로 적용).
  - 시야는 반경 5칸, 앞쪽 120°입니다. 청각은 2~7칸입니다.
  - 도망자보다 느려서 3~6턴마다 한 번 쉽니다.
- **도망자**
  - 시야 7칸, 청각 6칸으로 세 거인을 모두 추적합니다. 위험 지도는 세 거인 중 가장 가까운 거리를 기준으로 만듭니다.
  - 학습하는 능력으로 전력질주(2턴 동안 2칸씩 이동, 재사용 대기 20턴)가 있습니다.

## YouTube Live 송출 (stream/)

방송 모드: `http://localhost:8765/?stream=1` — 자동 시작·자동 다음 판, 3D 화면, 카메라 자동 전환(20초마다 도망자 추적 ↔ 전체 회전 조망),
큰 글씨 오버레이(점수·세대·레벨·최근 승률·역할·실시간 해설), 버튼 숨김. 판 사이마다 계속 학습하고 6판마다 15세대 고속 훈련(훈련 오버레이 표시).
뇌는 판마다 자동 저장되며, 오류 시 자동 새로고침, 60초 정지 감시, 4시간마다 새로고침.
URL 옵션: `q`(렌더 배율, 기본 0.75) · `shadow=0`(그림자 끔) · `fps`(렌더 상한, 기본 30).

```bash
cd stream
./start_stream.sh --test 20                      # YouTube 없이 20초 녹화 → ~/.cache/giant-escape-stream/test.mp4, test_frame.png, CPU 측정
YOUTUBE_STREAM_KEY=xxxx-xxxx-xxxx-xxxx ./start_stream.sh   # 실제 송출 (백그라운드 감시 프로세스)
./stop_stream.sh                                 # 중지 (게임 서버·터널은 건드리지 않음)
```

- 구성: Xvfb :99 (1280x720) → Chrome 키오스크 (3D는 Mesa llvmpipe, `CHROME_GL=swiftshader`로 대체 가능) → ffmpeg x11grab 30fps,
  libx264 veryfast 3500k, 키프레임 2초, yuv420p, 무음 AAC → `rtmp://a.rtmp.youtube.com/live2/<키>`
- 키가 없으면 오류로 종료. ffmpeg가 끊기면 5→60초 백오프로 자동 재시작, Chrome이 죽으면 5초 안에 다시 띄움.
- 로그: `~/.cache/giant-escape-stream/logs/` (stream.log, ffmpeg.log, chrome.log, xvfb.log) — 키는 `***REDACTED***`로 가려짐.
- 로그·테스트 영상·Chrome 프로필·PID 파일은 모두 웹 루트(터널로 공개됨) 밖 `~/.cache/giant-escape-stream/`에 보관 (`STREAM_STATE_DIR`로 변경 가능). stream/ 폴더에는 스크립트만 있음.
- 환경 변수: `STREAM_RES`, `STREAM_FPS`, `STREAM_BITRATE`, `DISPLAY_NUM`, `GAME_URL`, `LP_NUM_THREADS`(기본 4; 2로 낮추면 CPU↓ fps↓), `CHROME_CPUS`(taskset 코어 고정).
- 주의: 키는 ffmpeg 실행 인자에 들어가므로 실행 중 `ps`로는 보입니다(파일·로그에는 기록되지 않음).

  드래그(터치)로 잠깐 둘러보면 손을 뗀 뒤 원래 방향으로 복귀.
